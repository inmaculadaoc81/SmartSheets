# SmartSheets — web one-page

Abre `index.html` en un navegador o sube toda la carpeta al hosting. Mantén la estructura de `assets/`.

- `index.html`: estructura y contenido.
- `assets/css/styles.css`: estilos adaptables.
- `assets/js/main.js`: menú móvil y año automático.
- `assets/logo.webp`: logo optimizado.
- `assets/favicon.svg`: icono de pestaña.

Las ilustraciones y los iconos son SVG integrados en `index.html`, por lo que no necesitan archivos adicionales. Los datos de contacto de ejemplo deben sustituirse antes de publicar.
